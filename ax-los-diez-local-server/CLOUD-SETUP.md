# 아이패드 외부 접속 — 실제 배포 안내

PC를 켜 두지 않고 Safari에서 쓰는 **별도 호스팅 서버**용 준비 파일입니다. 저장소에 코드가 있다는 사실은 사이트가 배포되었다는 뜻이 아닙니다. 현재 사용자의 Render 계정·결제·외부 접속 주소·실제 모델 인증은 확인되지 않았습니다.

## 현재 준비된 것

- 블랙 UI, HTTPS 프록시 뒤에서 동작하는 개인 로그인, 보안 세션 쿠키와 로그아웃.
- 에이전트별(Marcelo·Paul) 모델/공급자 선택. API Key는 공급자별로 공유합니다.
- 문서·대화와 AI 개인 설정을 서로 다른 영구 디스크 폴더에 보관하는 배포 설정.
- PC 백업 ZIP을 브라우저에서 빈 저장소로 가져오는 기능. 기존 자료가 있으면 덮어쓰지 않습니다.
- PC 백업 ZIP 생성은 이제 Python 없이 Node.js로 처리합니다. 외부 배포판의 ZIP 가져오기는 컨테이너에 포함된 Python 3를 사용합니다.
- Docker 이미지 빌드와 512MiB 컨테이너의 문서/PDF/백업·재시작 보존 검사를 실행합니다. 이는 Render 실배포나 실제 아이패드 테스트를 대신하지 않습니다.

## 사용자에게 필요한 준비

1. [Render 대시보드](https://dashboard.render.com/)에서 GitHub 계정으로 가입·로그인합니다.
2. 웹 서버와 영구 디스크에 대한 **요금 확인**이 필요합니다. `render.yaml`은 유료 Starter 서비스와 1GB 디스크를 명시합니다. 워크스페이스가 무료여도 별도 서비스 요금이 있을 수 있습니다. 실제 월 요금·지역·결제 조건은 생성 화면에서 확인한 뒤 직접 승인하세요. 이 작업에서 유료 리소스를 생성하거나 결제하지 않았습니다.
3. OpenAI 또는 xAI API 계정과 사용 가능한 API 잔액·모델 권한이 필요합니다. ChatGPT/Grok 구독은 별도입니다. API Key나 비밀번호를 채팅에 보내지 마세요.

## Render에서 설정할 내용

Render의 Blueprint 생성 흐름에서 저장소 **monster527-prog/monster527**, 브랜치 **ax-los-diez-ipad-cloud-20261124**, 설정 파일 **render.yaml**을 선택합니다. 실제 계정 화면의 버튼 위치는 현재 확인하지 못했으므로, 다른 항목이 보이면 보이는 화면을 기준으로 진행해야 합니다.

구성이 맞는지 확인하세요.

| 항목 | 값 |
| --- | --- |
| Root Directory | 비워 둠 (저장소 루트) |
| Dockerfile Path | ./ax-los-diez-local-server/Dockerfile |
| Docker Build Context | ./ax-los-diez-local-server |
| 실행 환경 | Docker |
| 헬스 체크 | /healthz |
| 유료 인스턴스 | Starter (현재 가격은 Render 화면 확인) |
| 영구 디스크 | /var/data/ax, 1GB |
| AX_REMOTE | 1 |
| AX_WORLD_DATA_DIR | /var/data/ax/world-lab |
| AX_PRIVATE_SETTINGS_DIR | /var/data/ax/private |
| AX_ACCESS_PASSWORD | 사용자가 직접 정한 추측하기 어려운 12자 이상 로그인 비밀번호 |

`AX_ACCESS_PASSWORD`는 **AX 사이트 로그인용 비밀번호**이며 OpenAI/Grok API Key가 아닙니다. 코드에 기본 비밀번호를 넣지 않았고, 비밀번호가 없으면 외부 모드 서버가 시작되지 않습니다.

외부 주소는 Render가 제공하는 `RENDER_EXTERNAL_URL`을 사용합니다. 해당 변수가 제공되지 않으면 Render가 발급한 실제 HTTPS 주소를 `AX_PUBLIC_ORIGIN` 환경 변수로 설정해야 합니다. 주소를 임의로 만들어 입력하지 마세요.

자동 배포는 꺼져 있고 단일 인스턴스를 전제로 합니다. 여러 인스턴스로 자동 확장하지 마세요. Render Blueprint 설정의 실제 수락·외부 HTTPS 주소 발급은 사용자 계정에서 생성한 후에만 확인할 수 있습니다. 이 환경에서는 Render 문서 사이트 접속이 403으로 차단되어 요금과 공급자 설정 화면을 직접 읽지 못했습니다.

## 배포가 성공한 뒤

1. Render 상태가 실제 **Live**인지 확인하고, 서비스가 제공하는 **https://…onrender.com** 주소를 엽니다. `localhost` 주소가 아닙니다. 아직 실제로 발급된 주소를 확인하지 못했습니다.
2. `AX_ACCESS_PASSWORD`로 로그인합니다. 이 상태부터 PC 서버 없이 외부 네트워크의 아이패드에서도 사용할 수 있는 구조입니다. 실제 사용자 네트워크 접속은 Safari에서 확인해야 합니다.
3. 첫 저장소는 비어 있습니다. **PC 문서가 자동으로 옮겨지지 않습니다.** AHMN·안연사 PDF를 새 사이트에 등록하거나 WORLD LAB의 **백업 ZIP 가져오기**로 이전 자료를 복원합니다.
4. **AGENT CHAT → Marcelo → AI 연결 설정**에서 공급자·모델·키를 설정합니다. 외부 서버 재시작 후에도 키를 쓰려면 **이 서버에 키 보관**을 선택합니다. 호스팅 관리자 권한을 가진 사람은 이 설정 파일에 접근할 수 있습니다.
5. **Paul → AI 연결 설정**에서도 공급자와 모델을 고릅니다. 같은 공급자라면 키는 비워 두어 기존 키를 공유할 수 있습니다. 모델은 각자 따로 저장합니다. 예시 모델 ID의 실제 사용 가능 여부는 계정에서 확인해야 합니다.
6. 선택 문서와 API 비용 안내를 확인하고 Marcelo에게 **메시지 한 번**을 보냅니다. 응답에 실제 모델·응답 ID·토큰이 있는지 확인합니다. 다음으로 원하면 선택 답변을 Paul에게 전달하고 별도로 전송합니다. 자동 반복은 없습니다.
7. 답변을 Proposals에 보관하고 새로고침 후 다시 읽습니다. 승인/거절은 제안 판단만 남기며 Original을 자동 변경하지 않습니다.

## 기존 PC 자료 옮기기

- 오늘 PC의 기존 서버에서 **전체 세계관 백업 ZIP**을 받아 iCloud Drive 등 아이패드의 파일 앱에서 열 수 있는 곳에 보관하세요. API Key는 넣지 않습니다.
- 이전 버전에서 Python 부족으로 백업이 안 되면 새 버전을 별도 폴더에 풀고 `IMPORT-OLD-DATA.cmd`로 이전 `saved-world-lab`을 복사한 다음 실행하여 백업하세요. 새 버전의 브라우저 백업 생성에는 Python이 필요 없습니다.
- 새 사이트에서 WORLD LAB → **백업 ZIP 가져오기** → 파일 앱의 ZIP 선택 → 정본/대화 이력 복원 확인을 체크합니다. 64MiB까지 가져올 수 있습니다. 더 큰 자료는 문서별로 등록하세요.
- 새 사이트에 이미 파일이 있으면 복원을 거절합니다. 기존 자료를 지우고 강제로 덮어쓰는 기능은 넣지 않았습니다.
- 로그인 비밀번호와 API Key는 세계관 백업에 포함하지 않습니다. 새 서버에서 별도로 설정합니다.
- 영구 디스크도 삭제하거나 계정을 해지하면 사라질 수 있으므로 별도 백업을 유지하세요.

## 11월 25일 외부 사용 전 확인할 항목

- 아이패드의 Safari에서 실제 HTTPS 주소로 로그인한다.
- 집/회사 Wi-Fi가 아닌 외부 네트워크에서 문서와 대화를 다시 읽는다.
- 실제 API 인증으로 메시지 한 번을 보내고 모델 이름과 사용량을 확인한다.
- 앱을 닫았다 열고 저장된 자료가 유지되는지 확인한다.
- 실제 API 호출과 사용자 아이패드 확인이 끝나기 전에는 외부 사용 준비 완료로 보지 않는다.

## 직접 운영하는 경우의 실행 계약

`AX_REMOTE=1`은 신뢰할 수 있는 HTTPS 역방향 프록시 뒤에서 사용합니다. 프록시는 Host를 보존하고 `X-Forwarded-Proto: https`를 설정해야 합니다. 공개 원점과 접속 비밀번호가 없으면 시작하지 않습니다. HTTP 포트만 인터넷에 직접 공개하지 마세요. `/healthz`만 로그인 없이 상태를 반환하고 문서·모델 설정·백업·코드는 로그인 세션이 있어야 읽을 수 있습니다.

세션은 서버 메모리에 저장하므로 서버 재시작 후 재로그인이 필요합니다. 문서·대화·보관 선택한 공급자 키는 영구 디스크 경로에 있어야 재시작 후 유지됩니다. 키와 로그인 비밀번호는 GitHub·컨테이너 이미지에 포함하지 않습니다.
