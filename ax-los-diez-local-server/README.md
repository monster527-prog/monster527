# AX : LOS DIEZ · 블랙 UI / 아이패드 배포 준비판 v0.5.0

에이전트를 선택해 세계관을 참고하며 대화하는 개인 연구실입니다. 블랙 배경, 회색 말풍선, 컬러 아바타를 적용했습니다. 현재 채팅은 **Marcelo Brown과 Paul Rudolph**를 지원하며 나머지 10명은 미구현으로 표시합니다.

[블랙 화면 이미지](verification/black-chat-ready.png) · [개인 로그인 화면 이미지](verification/cloud-login.png) · [아이패드 외부 접속 배포 안내](CLOUD-SETUP.md)

코드와 이미지가 있다는 사실은 사이트가 배포되었다는 뜻이 아닙니다. 이 버전의 검증 시점에 실제 Render 계정·요금·외부 HTTPS 주소·실제 모델 인증·사용자 아이패드 접속은 아직 확인하지 못했습니다.

## 아이패드에서 PC 없이 사용

[CLOUD-SETUP.md](CLOUD-SETUP.md)를 따라 별도 호스팅 서버에 배포합니다. 저장소 루트 `render.yaml`은 Render의 **유료 Starter 서비스 + 1GB 영구 디스크**를 지정합니다. 실제 생성 화면의 가격을 확인한 뒤 직접 승인해야 합니다. 배포용 계정·결제·사이트를 자동 생성하지 않았습니다.

배포 후 발급된 HTTPS 주소를 Safari에서 열고 작업 공간 비밀번호로 로그인합니다. 같은 Wi-Fi나 켜진 PC는 필요 없는 구조입니다. 실제 주소 발급과 사용자 외부 네트워크 검증은 계정에서의 배포 이후에 가능합니다. `localhost`와 CMD 실행은 PC 로컬 모드 전용입니다.

## PC 로컬 사용·기존 문서 이전

1. Node.js **22.13 이상(권장 LTS 24)**을 [공식 사이트](https://nodejs.org/)에서 설치합니다. npm install은 필요하지 않습니다.
2. ZIP을 새 폴더에 완전히 풀고 기존 서버를 Ctrl+C로 종료합니다. 이전 폴더는 삭제하지 마세요.
3. 새 서버를 켜기 **전에** `IMPORT-OLD-DATA.cmd`에서 이전 `saved-world-lab` 폴더의 전체 경로를 입력합니다. 전체 파일을 복사·해시 확인하며 새 데이터가 있으면 덮어쓰지 않습니다.
4. `START-WINDOWS.cmd`를 실행합니다. 서버 준비 후 브라우저를 자동으로 열도록 구성했습니다. 창에 **AX server READY**가 있는지 확인하고 창을 닫지 마세요. 실제 Windows 자동 열기 성공은 아직 미확인입니다.
5. 자동으로 열리지 않으면 같은 PC에서 **http://127.0.0.1:33000/#chat**을 엽니다. HTML 파일을 직접 열면 저장 서버에 연결되지 않습니다.
6. 접속 실패 시 `CHECK-SERVER-WINDOWS.cmd`를 실행합니다. 보고서에는 모델 키·로그인 비밀번호·문서·대화 본문을 넣지 않습니다.

macOS/Linux는 `sh START-MAC-LINUX.command`, 이전 폴더 가져오기는 `node scripts/import-old-data.mjs`입니다. 기본 로컬 모드는 루프백만 사용하며 다른 기기에서 접속할 수 없습니다.

## 에이전트마다 API 연결

- **Marcelo 선택 → AI 연결 설정**에서 공급자·모델·API Key를 입력합니다. **Paul 선택 → AI 연결 설정**에서도 원하는 공급자와 모델을 고릅니다.
- 공급자는 OpenAI 또는 xAI/Grok입니다. 모델은 에이전트마다 따로 저장하고 **같은 공급자의 키는 공유**합니다. 같은 공급자라면 두 번째 에이전트 설정에서 키를 비워 기존 키를 사용할 수 있습니다.
- 예시 모델 ID는 OpenAI `gpt-4.1-mini`, xAI `grok-4`입니다. 실제 계정에서 사용할 수 있는 모델 ID를 입력해야 합니다. 예시의 사용 가능 여부는 아직 확인하지 못했습니다.
- 키는 [OpenAI API 콘솔](https://platform.openai.com/api-keys) 또는 [xAI 콘솔](https://console.x.ai/)에서 발급합니다. **ChatGPT/Grok 앱 구독과 API 요금은 별개**입니다.
- API Key는 설정 창에만 입력하고 채팅으로 보내지 마세요. 기본은 서버 메모리 보관이며 재시작하면 다시 입력해야 합니다. **이 서버에 키 보관**을 선택하면 개인 설정 파일에 저장합니다. 로컬에서는 PC, 외부 배포에서는 호스팅 영구 디스크에 저장됩니다. 서버 관리자 권한이 있으면 읽을 수 있습니다.
- 키 등록은 인증 성공과 다릅니다. 사용자가 전송을 눌렀을 때만 실제 API를 호출하고 실제 반환 모델·응답 ID·사용량을 기록합니다. 인증이 없거나 실패하면 가상 답변으로 대체하지 않습니다.

이 채팅은 역할 지침을 적용한 모델 API 대화이며 Codex Custom Agents 실행기를 호출하는 방식은 아닙니다. 기존 에이전트 정의 파일을 수정하지 않았습니다.

## 세계관을 참고하는 대화

1. 세계관과 참고 문서를 고릅니다. **현재 승인된 Original과 Development 중 본문 추출이 끝난 문서**만 선택할 수 있습니다. TEST ONLY 문서는 모델에도 그 상태로 전달합니다.
2. 문서·대화의 선택 공급자 전송과 API 비용 안내에 동의한 뒤 전송합니다. 원본이 선택되지 않으면 정본 대조를 했다고 말하지 않도록 지시합니다. 문서가 없을 때의 일반 대화도 가능합니다.
3. Marcelo는 기존 정체성을 유지하며 소주제 하나를 발전시킵니다. **Paul에게 이 답변 평가 요청**은 선택 답변만 Paul 대화에 연결합니다. Paul의 **전송을 별도로 눌러야** 평가 호출이 시작됩니다. 서로의 전체 대화를 자동 공유하지 않습니다.
4. 답변의 **Proposals에 보관**으로 질문·응답·출처 해시·실제 모델 기록을 저장합니다. WORLD LAB에서 제안 승인/거절과 메모를 기록할 수 있습니다. **Original은 자동 변경하지 않습니다.**

모델에 전송하는 자기 대화는 최근 완료 대화 최대 20회·5만 자, 선택 문서 본문은 16만 자, 사용자 메시지는 8,000자, 출력은 최대 2,400토큰입니다. 문서 한도를 넘으면 임의로 자르지 않고 중단합니다. 실제 공급자 한도와 요금은 다를 수 있습니다.

전송 한 번에 호출 한 번이며 자동 반복·예약·자동 재시도는 없습니다. 중간에 연결이 끊기면 먼저 기록과 공급자 사용 내역을 확인하세요. 공급자 측 비용이 발생했을 수 있습니다.

## PDF와 원본 보호

- PDF·TXT·MD의 업로드 파일과 추출 텍스트를 별도로 보관합니다. 일반 텍스트 PDF는 번들 PDF.js로 처리하므로 Poppler가 필요하지 않습니다. 스캔/윤곽선 PDF의 OCR은 아직 미구현입니다.
- WORLD LAB의 **PDF 진단** 또는 `CHECK-PDF-WINDOWS.cmd`에서 내장 추출기와 선택적 Poppler 설치·경로를 확인합니다.
- **텍스트 다시 추출**은 기존 `original.pdf`, `text.txt`, `metadata.json`을 덮어쓰지 않습니다. 새 결과를 `extractions/<ID>/`에 추가합니다. 실패한 결과로 성공한 본문을 비우지 않습니다.
- 승인된 Original은 본문을 고정하므로 재추출을 거절합니다. 변경하려면 새 후보를 등록하고 직접 승인해야 합니다. Proposals 승인도 정본 승격이 아닙니다.
- 표지·이미지·가상 작업 상태는 기존 DEMO입니다. ARCHIVE의 서적 항목은 서지/색인으로, 책 전문을 배포하지 않습니다.

## 저장·백업·외부 이전

기본 로컬 자료는 `saved-world-lab`, 기본 로컬 AI 설정은 `private-settings/ai.json`입니다. 외부 배포는 각각 영구 디스크의 `/var/data/ax/world-lab`, `/var/data/ax/private/ai.json`을 사용합니다. 키 설정은 자료 백업과 분리합니다.

**전체 세계관 백업 ZIP**은 Node.js로 생성하며 PC에서 Python을 설치할 필요가 없습니다. 원본·추출 이력·메타데이터·승인/제안 판단·대화와 문서 스냅샷을 포함합니다. 파일 SHA-256 목록도 넣습니다. 문서나 메시지에 사용자가 직접 적은 비밀정보는 자료가 되므로 키를 붙여넣지 마세요.

외부 사이트는 처음에 빈 저장소입니다. 기존 PC 파일이 자동으로 옮겨지지 않습니다. **백업 ZIP 가져오기**에서 64MiB 이하 백업을 업로드하면 빈 저장소에만 복원합니다. 경로·압축 크기·해시와 원본을 검사하고 기존 자료가 있으면 거절합니다. 가져오기 도구는 호스팅 컨테이너에 포함된 Python 3를 사용합니다. PC에서는 Python 3가 있거나 기존 폴더 가져오기 도구를 사용할 수 있습니다.

디스크 삭제·서비스 해지 시 자료가 사라질 수 있으므로 별도 백업을 유지하세요. Docker/호스팅은 단일 인스턴스를 전제로 합니다.

## 검증과 한계

- `npm run check`, `npm test`: 문법·저장·PDF 복구·모델 API 요청 형식·대화 분리·접속 차단·로그인·복원 안전 검사. 개발용 PDF 생성에는 Python/reportlab이 필요합니다.
- `node tests/chat-ui.mjs`, `node tests/cloud-ui.mjs`: Playwright/Chromium 브라우저 검사. `AX_PLAYWRIGHT_MODULE`, `CHROMIUM_PATH` 지정 가능. 클라우드 브라우저 검사는 로컬 HTTPS 프록시와 시험용 인증서를 사용하며 테스트 모델 대역으로 동작합니다.
- 컨테이너 빌드·512MiB 실행·PDF 추출·볼륨 유지 교체·백업을 검사했습니다. 실제 Render 배포는 아닙니다.
- 검증 시 실제 외부 모델 호출은 **0회**입니다. 키가 없어 실제 인증·모델 가용성·요금은 미확인입니다. 테스트 대역은 운영 시작에서 로드하지 않습니다.
- 실제 사용자 Windows/iPad/Safari와 외부 네트워크 접속은 아직 미확인입니다. 검증 기록과 화면은 `verification/`에 있습니다.
