# 선명한 블랙 UI · 접속 안내 개선 (v0.4.1)

참고 이미지처럼 녹색 기운을 줄인 블랙 배경, 회색 말풍선, 에이전트별 컬러 아이콘을 적용했습니다. 채팅 화면의 앱 메뉴는 좁은 아이콘 레일로 표시하여 대화 공간을 넓혔습니다. 문서·대화·Original 보호 기능은 유지합니다.

## Windows에서 여는 순서

1. 새 ZIP을 별도 폴더에 압축 해제하고 `ax-los-diez-local-server` 폴더를 엽니다. 이전 서버는 Ctrl+C로 종료하고 이전 데이터는 삭제하지 마세요.
2. 새 서버를 먼저 켜지 말고 `IMPORT-OLD-DATA.cmd`로 이전 `saved-world-lab`을 가져옵니다.
3. `START-WINDOWS.cmd`를 실행합니다. **서버가 실제로 준비된 뒤 기본 브라우저를 열도록 구성했습니다.** 창을 닫지 마세요.
4. 창에 **AX server READY**가 보이는지 확인합니다. 창이 열려 있다는 사실만으로 서버 실행 성공을 뜻하지 않습니다.
5. 자동으로 브라우저가 열리지 않으면 같은 PC에서 **http://127.0.0.1:33000/#chat**을 엽니다. `index.html` 파일을 직접 열면 서버 기능을 사용할 수 없습니다.
6. AGENT CHAT에서 Marcelo 또는 Paul을 선택하고 **AI 연결 설정**에서 API Key를 등록합니다. 키 등록은 실제 모델 인증 성공과 다르며, 실제 메시지 전송에서 확인합니다. API 요금은 웹 구독과 별개입니다.

자동 브라우저 실행은 Windows에서 `rundll32.exe`의 기본 URL 처리기를 사용합니다. 실제 사용자 Windows에서의 자동 실행 성공은 아직 확인하지 못했습니다. 실패하면 위 주소로 직접 접속할 수 있습니다.

## 연결되지 않을 때

- **HTML 파일을 직접 연 상태**: 서버를 시작하고 자동으로 열린 브라우저를 사용하세요. 파일 미리보기는 실제 서버 연결이 아닙니다.
- **ERR_CONNECTION_REFUSED / 서버 응답 없음**: 33000번 서버가 준비되지 않은 상태입니다. `START-WINDOWS.cmd` 창에서 READY 또는 오류 메시지를 확인하세요.
- **포트가 이미 사용 중**: 이전 서버를 종료한 뒤 새 버전을 실행하세요. 프로그램은 다른 서버를 강제로 종료하지 않습니다.
- **채팅 API 없음**: 이전 버전 서버 또는 다른 정적 서버일 수 있습니다. 이전 창을 종료하고 새 폴더의 실행 파일을 사용하세요.
- **API Key가 없습니다**: 로컬 서버 연결 이후의 별도 모델 설정 단계입니다.
- **이번 버전 채팅 미지원**: 해당 에이전트는 미구현입니다. 네트워크 연결 상태가 아닙니다. 현재 Marcelo·Paul만 대화할 수 있습니다.

**CHECK-SERVER-WINDOWS.cmd**를 실행하면 Node.js 버전, 로컬 서버 응답, 채팅 API 유무와 키 등록 여부를 확인하여 `server-diagnostics.json`으로 남깁니다. API Key 값·CSRF 토큰·세계관 본문·대화 내용은 보고서에 넣지 않습니다. 공급자 모델 호출도 하지 않습니다. 오류 문구를 확인해 주세요.

## 아이패드 사용 범위

이 UI는 PC·태블릿 크기에 맞춰 표시되지만, **현재 배포물은 PC 로컬 서버 패키지**입니다. 아이패드에서는 CMD를 실행할 수 없고 아이패드의 localhost/127.0.0.1은 사용자 PC가 아닙니다. 현재 서버는 PC의 루프백 인터페이스에만 바인딩하고 원격 접속을 허용하지 않습니다.

아이패드에서 문서 업로드·채팅을 실제로 사용하려면 로그인·암호화로 보호되는 웹 접속 경로를 별도로 구성해야 합니다. 이 패키지는 그 배포나 사용자 인증을 구성하지 않았으며 아이패드 단독 실행이 된다고 주장하지 않습니다. 태블릿 크기의 화면 검사는 실제 iPad/Safari 하드웨어 검증과 다릅니다.

# AX : LOS DIEZ — AGENT CHAT (v0.4.0)

기존 다크 모드 디자인에 **AGENT CHAT / 에이전트 대화**를 추가했습니다. 현재 Marcelo Brown과 Paul Rudolph를 선택할 수 있고, 나머지 10명은 연결 준비 중으로 표시합니다. 이 채팅은 역할 지침을 적용한 모델 API 대화이며 Codex Custom Agents 실행기를 호출하는 방식은 아닙니다. 기존 `.codex/agents` 정의는 수정하지 않았습니다.

## 설치·업데이트

Node.js **22.13 이상(권장 LTS 24)**이 필요합니다. [Node.js 공식 사이트](https://nodejs.org/)에서 설치하세요. npm install이나 별도 AI 프로그램 설치는 필요하지 않습니다.

1. 이 브랜치에서 **Code → Download ZIP**을 선택합니다. 새 폴더에 완전히 압축 해제하고 `ax-los-diez-local-server` 폴더를 엽니다. 이전 폴더에 덮어쓰지 마세요.
2. 기존 서버를 Ctrl+C로 종료합니다. 새 서버를 실행하기 **전에** `IMPORT-OLD-DATA.cmd`를 실행합니다.
3. 이전 `saved-world-lab` 폴더의 전체 경로를 붙여넣습니다. 탐색기에서 그 폴더를 열고 주소창을 클릭해 경로를 복사하면 됩니다. 가져오기는 복사와 해시 검증을 수행하고 기존 자료를 남깁니다. 새 저장 폴더가 이미 있으면 덮어쓰지 않고 중단합니다.
4. `START-WINDOWS.cmd`를 실행하고 같은 PC의 브라우저에서 **http://localhost:33000**을 엽니다. 실행 창은 열어 두세요.
5. 왼쪽 메뉴의 **AGENT CHAT**을 선택합니다. macOS/Linux는 `sh START-MAC-LINUX.command`로 실행합니다.

## 실제 모델 연결

이 패키지에는 API Key가 포함되어 있지 않습니다. ChatGPT 또는 Grok의 웹/앱 구독과 API 요금은 별개입니다.

1. 채팅 화면 오른쪽 위 **AI 연결 설정**을 누릅니다.
2. **OpenAI** 또는 **xAI / Grok**를 선택합니다.
3. 공급자의 API 콘솔에서 키를 발급합니다: [OpenAI API Key](https://platform.openai.com/api-keys), [xAI 콘솔](https://console.x.ai/). 사용 가능한 잔액·결제와 모델 권한이 필요합니다.
4. 해당 계정에서 사용할 수 있는 **모델 ID**와 **API Key**를 설정 창에 넣습니다. 기본 예시는 OpenAI `gpt-4.1-mini`, xAI `grok-4`이며 계정에서의 사용 가능 여부는 아직 확인되지 않았습니다. 모델 ID는 직접 바꿀 수 있습니다.
5. **이 PC에 키 보관**은 기본 해제입니다. 해제 상태에서는 새 키를 서버 메모리에서만 사용하므로 서버 재시작 후 다시 입력해야 합니다. 체크하면 앱 폴더의 `private-settings/ai.json`에 저장합니다. 이 파일은 GitHub·배포 ZIP·세계관 백업에서 제외합니다. Windows 파일 관리자 권한이 있는 사람은 파일을 읽을 수 있습니다.
6. 키를 저장했다는 표시가 실제 인증 성공은 아닙니다. 최초 메시지를 전송하면 공급자가 인증하며, 오류 시 원인을 표시하고 가상 답변으로 대체하거나 자동 재호출하지 않습니다.

고급 설정으로 서버 실행 환경의 `OPENAI_API_KEY` 또는 `XAI_API_KEY`를 사용할 수도 있습니다. 키는 채팅 메시지에 붙여넣지 마세요. 키 설정은 이전 데이터 가져오기로 자동 복사되지 않습니다.

## 대화와 세계관 발전

- 왼쪽에서 Marcelo 또는 Paul, 위쪽에서 AHMN·중간계·안연사·언네임드1·언네임드2를 선택합니다.
- **참고 문서 선택**에서 현재 승인된 Original과 Development를 고릅니다. 추출 실패·OCR 필요 문서는 사용할 수 없습니다. 승인 전 Original 후보·과거 Original·Proposals·다른 에이전트 대화는 자동 참고하지 않습니다.
- 문서가 없어도 일반 대화는 가능하지만 정본을 읽었다고 주장하지 않도록 지시합니다. TEST ONLY 문서는 모델에 그 상태로 전달됩니다.
- 모델 공급자 전송·API 요금 안내에 동의한 뒤 **전송**을 누릅니다. 선택한 본문과 최근 자기 대화가 선택한 공급자로 전송됩니다. 자료 속 지시문은 참고 데이터로 취급하며 모델에 파일 쓰기·외부 검색·다른 에이전트 호출 도구를 주지 않습니다.
- Marcelo에게 기존 정체성을 유지할 소주제 하나를 제안받고, 원하는 답변 아래 **Paul에게 이 답변 평가 요청**을 누르면 Paul 대화의 평가 대상으로 선택됩니다. **전송을 한 번 더 눌러야** Paul 모델 호출이 시작됩니다. 선택한 답변만 전달하며 Marcelo의 전체 대화는 넘기지 않습니다.
- 답변 아래 **Proposals에 보관**으로 질문·응답·모델·응답 ID·문서 해시·토큰 기록을 WORLD LAB에 저장할 수 있습니다.
- WORLD LAB의 Proposals에서 **제안 승인 / 거절**과 메모를 기록합니다. 이는 제안 판단이며 **Original 자동 반영이 아닙니다.** 이미 기록한 판단은 덮어쓰지 않습니다.

Marcelo와 Paul은 역할이 다른 별도 대화지만 동일한 공급자·모델을 사용할 수 있습니다. 서로 다른 모델을 사용했다고 주장하지 않습니다. 이미지 자료가 없으면 Paul의 이미지 미학 평가는 미실시입니다. 설정 일관성 판단도 모델의 제안이며 사용자의 검토가 필요합니다.

## 저장과 한도

- 전체 대화·문서 스냅샷·실제 응답 모델·응답 ID·사용량은 `saved-world-lab/chats/<세계관>/<에이전트>/<전송ID>/`에 보관합니다. 새로고침과 재시작 후 다시 읽습니다.
- 모델에 보내는 대화는 해당 에이전트·세계관의 최근 완료 대화 최대 20회·5만 자입니다. 전체 과거 대화가 매번 모델에 전달되지는 않습니다.
- 선택 문서 본문 16만 자, 메시지 8,000자, 출력 최대 2,400토큰, 호출 대기 90초입니다. 문서 한도를 넘으면 임의로 자르지 않고 호출을 중단합니다. 공급자·모델에 따라 실제 지원 한도와 추가 비용은 다를 수 있습니다.
- 메시지 전송 한 번에 모델 호출 한 번입니다. 자동 반복·예약·자동 재시도는 없습니다. 중간에 연결이 끊기거나 서버가 종료되면 자동 재실행하지 않습니다. 공급자 측 요금이 발생했을 수 있으므로 대화 기록과 공급자 사용 내역을 먼저 확인하세요.
- Original 파일과 승인 이력은 채팅·제안 보관·제안 판단으로 변경하지 않습니다. 모델이 승인했다고 말해도 시스템 승인이 되지 않습니다.
- `private-settings`는 세계관 데이터와 별도이며 백업에 넣지 않습니다. 세계관 데이터는 비공개로 보관하고 저장 폴더를 삭제하지 마세요. 앱은 localhost 전용 개인 작업용입니다.

## 검증 상태

API Key가 없는 이 환경에서 **실제 외부 모델 호출은 0회**입니다. 인증 없는 실행 차단, API 요청 형식, 대화 분리·저장, 모델 응답 메타데이터, Paul 전달, 제안 보관·판단, PDF 복구는 자동 테스트로 검사했습니다. API 응답 경로 테스트와 브라우저 전송 시험은 명확히 표시된 격리 테스트 대역을 사용했습니다. 배포 서버는 테스트 대역을 로드하지 않으며 가상 답변 경로를 제공하지 않습니다. 실제 계정의 인증·모델 가용성·과금 및 사용자 Windows 실행은 아직 미확인입니다.

개발 검증: `npm test`, `npm run check`. 브라우저 시험은 `AX_PLAYWRIGHT_MODULE`, `CHROMIUM_PATH`를 지정하고 `node tests/chat-ui.mjs`를 실행합니다. 테스트를 위한 Playwright·Chromium·Python/reportlab은 개발 환경에서만 필요합니다. 사용자에게 모델 API Key를 채팅으로 요청하거나 대신 보관하지 않습니다.

# AX : LOS DIEZ — PDF 복구판 (2026-11-24)

화면 디자인은 유지하고 PDF 추출·진단·재추출 기능을 추가한 Windows 로컬 서버입니다. Node.js 외의 프로그램 설치 없이 일반 텍스트 PDF를 읽도록 Mozilla PDF.js 6.5.438과 필요한 한글 CMap·글꼴·라이선스를 함께 배포합니다. PDF를 외부 서비스로 보내지 않습니다.

## 먼저 알아둘 점

- **Node.js 22.13 이상(권장: 현재 LTS 24)**이 필요합니다. [공식 설치 페이지](https://nodejs.org/)에서 LTS를 설치하세요. 이전 Node.js 20에서는 시작을 중단하고 업그레이드를 안내합니다.
- Poppler는 선택입니다. 일반 텍스트 PDF는 내장 PDF.js로 먼저 처리합니다.
- 스캔 이미지·글자 윤곽선만 있는 PDF는 별도 OCR이 필요합니다. OCR 기능은 이번 패키지에 포함하지 않았습니다. 빈 본문을 성공으로 표시하지 않습니다.
- 사용자 Windows PC의 설치 상태와 AHMN·안연사 PDF 실물은 이 클라우드에서 확인할 수 없었습니다. 설치 부족·암호·손상·OCR 필요 여부는 새 진단 기능으로 구분합니다.

## 다운로드와 기존 문서 가져오기

1. 이 브랜치의 **Code → Download ZIP**으로 받아 **새 폴더**에 압축을 완전히 풉니다. 이전 폴더에 덮어쓰지 마세요.
2. 기존 서버 창에서 **Ctrl+C**로 서버를 종료합니다. 이전 폴더와 `saved-world-lab`은 삭제하지 마세요.
3. 새 `ax-los-diez-local-server` 폴더의 **IMPORT-OLD-DATA.cmd**를 실행합니다. 새 서버를 먼저 실행하지 마세요.
4. 이전 `saved-world-lab` 폴더의 전체 경로를 붙여넣고 Enter를 누릅니다. 예: `C:\Users\이름\Downloads\이전버전\ax-los-diez-local-server\saved-world-lab`.
5. 이 도구는 파일을 **복사**하고 SHA-256을 비교합니다. 기존 데이터는 그대로 남습니다. 새 저장 폴더가 이미 있으면 덮어쓰지 않고 중단합니다. 이 경우 다시 새 폴더에 ZIP을 풀어 가져오세요.
6. 새 폴더에서 **START-WINDOWS.cmd**를 실행합니다. 브라우저에서 **http://localhost:33000**을 엽니다.
7. AHMN 또는 안연사를 선택하고 기존 PDF를 엽니다. **텍스트 다시 추출 → 다시 추출 시작**을 누릅니다. 파일을 다시 업로드할 필요가 없습니다.
8. 본문을 확인하고 새로고침한 뒤 다시 엽니다. **추출 이력**에서 상태와 오류 코드를 확인할 수 있습니다.

자동 가져오기 대신 탐색기에서 이전 `saved-world-lab` 폴더를 새 앱 폴더 안으로 전체 복사해도 됩니다. 서버를 종료한 상태에서, 아직 새 저장 폴더가 없을 때 복사하세요. 일부 문서 폴더만 옮기면 승인 이력이 누락될 수 있습니다.

macOS/Linux는 폴더의 터미널에서 `sh START-MAC-LINUX.command`로 실행합니다. 가져오기 도구는 `node scripts/import-old-data.mjs`로 실행할 수 있습니다.

## PDF 진단

WORLD LAB의 **PDF 진단** 버튼은 서버가 실제 사용 중인 Node.js 버전, 내장 추출기 준비 여부, Poppler 설치 여부, 실행 경로/명령, 버전 또는 오류 코드를 보여줍니다. 설치된 것을 확인하지 못하면 설치됐다고 표시하지 않습니다.

Windows의 **CHECK-PDF-WINDOWS.cmd**를 실행하면 같은 정보를 보고 `pdf-diagnostics.json`으로 남깁니다. 이 보고서에는 PC 프로그램 경로가 들어가므로 공유 전 확인하세요.

이전 버전은 `pdftotext` 실행 파일 없음(ENOENT), 실행 권한 문제, 암호 PDF, 손상 PDF 등을 모두 하나의 일반 오류로 표시했습니다. 이전 오류 메시지만으로 사용자 PC의 실제 원인을 확정할 수 없습니다.

## Poppler를 선택적으로 설치하려면

내장 추출기로 읽히면 설치하지 않아도 됩니다. 필요하다면:

1. [Windows Poppler 배포 페이지](https://github.com/oschwartz10612/poppler-windows/releases)에서 최신 Release ZIP을 받습니다. 이는 별도 Windows 배포본입니다.
2. 예를 들어 `C:\Tools\poppler`에 압축을 풉니다. 버전 폴더가 한 단계 더 생길 수 있습니다.
3. 탐색기에서 실제 **pdftotext.exe**를 찾습니다. 보통 `Library\bin` 안에 있습니다.
4. Windows 검색에서 **환경 변수 편집 → 환경 변수 → 사용자 변수 Path → 편집 → 새로 만들기**를 열어, 실제 `pdftotext.exe`가 든 폴더 경로를 추가합니다. EXE 파일 자체가 아닌 폴더입니다.
5. 기존 서버 창을 닫고 다시 실행한 다음 **PDF 진단**에서 설치 상태와 경로를 확인합니다. PATH 변경 전에 열린 서버에는 새 설정이 적용되지 않습니다.

고급 설정으로 `AX_PDFTOTEXT_PATH` 환경 변수에 pdftotext.exe의 전체 경로를 지정할 수도 있습니다. 팝플러는 내장 추출기가 실패하거나 본문을 찾지 못했을 때만 보조로 사용합니다.

## 원본·텍스트·이력 보존

기존 `original.pdf`, `text.txt`, `metadata.json`은 재추출로 변경하지 않습니다. 새 결과는 같은 문서의 `extractions/<추출ID>/text.txt`와 `extraction.json`에 추가합니다. 파일 해시·추출기·시각·오류 코드도 기록합니다. 실패한 재추출이 이미 성공한 본문을 빈 텍스트로 대체하지 않습니다.

승인된 Original의 본문은 고정되어 재추출을 거절합니다. 필요한 경우 사용자 판단으로 새 후보를 등록해야 합니다. PDF 복구 작업이 자동 승인하거나 정본 버전을 바꾸지는 않습니다. 서버를 다시 시작해도 저장된 추출 이력을 읽습니다.

`전체 세계관 백업 ZIP`은 기존 방식대로 Python 3가 필요합니다. PDF 업로드·추출·재추출·가져오기에는 Python 또는 Poppler 설치가 필요하지 않습니다. 별도로 `saved-world-lab` 폴더 전체를 안전한 디스크에 복사해 둘 수도 있습니다. GitHub에는 개인 문서나 저장 데이터를 업로드하지 않습니다.

## 검증 범위

Linux / Node.js 24에서 Poppler를 일부러 찾을 수 없게 한 환경으로 한글·여러 쪽 PDF 추출, 기존 실패 자료 복구, 원본 보존, 암호/스캔 구분, 승인된 원본 차단, 서버 재시작 후 읽기와 브라우저 본문 표시를 검사합니다. 사용자 Windows PC·실제 AHMN/안연사 PDF의 성공을 확인했다고 주장하지 않습니다.

개발 테스트: `node --test tests/pdf-recovery.test.mjs tests/world-storage.test.mjs` (시험 PDF 생성에는 개발용 Python/reportlab 필요). 브라우저 테스트는 Playwright와 Chromium이 필요합니다. `AX_PLAYWRIGHT_MODULE`, `CHROMIUM_PATH`로 경로를 지정할 수 있습니다. 검증 기록은 `verification/`에 있습니다.

PDF 처리는 모델 호출 없이 로컬에서 수행합니다. AI 대화는 위 AGENT CHAT 안내를 참고하세요. 기존 에이전트·이미지 기록은 DEMO이며 실제 파일은 TEST ONLY 또는 실제 등록 문서로 구분합니다.
